# MOVE30

Sistema experimental de cadastro MOVE 30, API FastAPI, dashboards Streamlit e estrutura de ingestão para hardware ESP32.

## Estrutura
- frontend/: formulário público de cadastro
- backend/: API, processamento e migrações PostgreSQL
- Dashboard/: dashboards pessoal e coletivo
- DOCUMENTACAO_PROJETO_BRUTO.md: histórico original preservado

Use .env.example como referência para configurar o ambiente local. Não publique .env nem credenciais reais.
